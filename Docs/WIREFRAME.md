# MyLink - 화면 와이어프레임 (Wireframe)

본 문서는 마이링크 서비스의 소유자(관리 모드) 화면에 대한 아스키 아트(ASCII Art) 형태의 와이어프레임입니다.

## 1. 마이페이지 관리 모드 화면 구조
- **디자인 컨셉:** 기존 화이트 미니멀리즘 테마 (반응형 1단/다단 구조)
- **특징:** 모든 수정(이름, 소개글, 링크)은 다이얼로그나 팝업 화면 이동 없이 화면 내 직접(인라인)에서 처리됩니다.

```text
+-------------------------------------------------------------------------+
|                                                     [내 페이지 보기] ↗  |
|                                                                         |
|                               BORA JO ✏️                                |
|                               -------                                   |
|                        DEPARTMENT OF CLOTHING ✏️                        |
|                                                                         |
|      an experimental platform exploring the structural boundaries... ✏️ |
|                                                                         |
| ----------------------------------------------------------------------- |
|                                                                         |
|  [F] INSTAGRAM                                                  [❌]    |
|      URL: https://instagram.com/4ora_                           [✏️]    |
|                                                                         |
| ----------------------------------------------------------------------- |
|                                                                         |
|  [P] PORTFOLIO (COMING SOON)                                    [❌]    |
|      URL: https://portfolio.com                                 [✏️]    |
|                                                                         |
| ----------------------------------------------------------------------- |
|                                                                         |
|  [ + 새로운 링크 추가하기 ]                                             |
|                                                                         |
|                                                                         |
|                                                                         |
|                           SEOUL, SOUTH KOREA                            |
|                  © 2026 BORA JO. ALL RIGHTS RESERVED.                   |
|                                                                         |
+-------------------------------------------------------------------------+
```

### 1.1. 주요 컴포넌트 설명
- **`[내 페이지 보기] ↗` 버튼:** 화면 우측 상단에 고정된 버튼으로, 클릭 시 방문자에게 보여지는 실제 퍼블릭 프로필 화면으로 이동합니다.
- **`✏️` 연필 아이콘:** 
  - 닉네임(`BORA JO`)이나 소개글(`DEPARTMENT OF CLOTHING`, 기타 내용) 옆에 항상 노출되어 직관적으로 수정 가능함을 안내합니다.
  - 클릭 시 해당 텍스트 영역이 입력 가능한 인라인 폼으로 변경됩니다.
- **링크 아이템 관리:**
  - `[F]`, `[P]`: 입력된 URL에 따라 구글 파비콘 API에서 가져온 이미지가 표시되는 영역입니다.
  - `[❌]`: 해당 링크를 삭제하는 버튼입니다.
  - `[✏️]`: 링크 텍스트나 URL을 인라인 편집 모드로 전환하는 버튼입니다.
- **방문자 화면 비교:** 실제 방문자가 접속했을 때는 편집용 아이콘(`✏️`, `❌`)과 우측 상단의 `[내 페이지 보기]` 버튼이 모두 렌더링되지 않습니다.
