# MyLink - 사용자 시나리오 (User Scenario)

본 시나리오는 마이링크 서비스의 두 가지 핵심 역할(소유자, 방문자)을 기준으로 작성되었습니다.

## 1. 방문자 (Visitor) 시나리오
- 사용자는 특정 크리에이터의 프로필과 작업물을 확인하기 위해 **제공된 프로필 URL(예: mylink.com/hello)로 접속**한다.
- 사용자는 크리에이터가 전시한 정보를 탐색하고, 관심 있는 목적지로 이동하기 위해 **리스트 내의 특정 링크 항목을 클릭**한다.
- 사용자는 외부 페이지로 이동하며, 이때 시스템은 **해당 링크의 클릭 조회수를 1 증가시키기 위해 백그라운드에서 통계 데이터를 업데이트**한다.

## 2. 소유자 (Owner / 마이페이지 관리 모드) 시나리오
- 사용자는 자신의 마이링크 프로필을 생성하거나 관리하기 위해 **메인 화면에서 구글 소셜 로그인 버튼을 클릭하여 인증**한다.
- 사용자는 신규 가입 시 자신만의 고유한 링크 주소를 부여받기 위해 **구글 이메일 앞부분(ID)을 기반으로 생성된 주소(displayName)를 자동으로 할당**받는다.
- 사용자는 실제 방문자들에게 자신의 페이지가 어떻게 보이는지 확인하기 위해 **화면 우측 상단에 고정된 '내 페이지 보기' 버튼을 클릭**한다.
- 사용자는 프로필에 표시되는 자신의 이름(username)이나 소개글(bio)을 최신화하기 위해 **텍스트 옆에 항상 표시되어 있는 직관적인 연필(✏️) 아이콘을 클릭하여 인라인에서 즉시 수정**한다.
- 사용자는 새로운 포트폴리오나 외부 플랫폼 주소를 등록하기 위해 **링크 목록 하단의 '+ 링크 추가'를 클릭한 뒤 인라인 방식으로 제목과 URL을 입력**한다.
- 사용자는 기존에 등록한 링크의 내용이 변경되었을 때, 폼 이동 없이 즉각적으로 반영하기 위해 **수정하고자 하는 링크의 텍스트(또는 옆의 연필 아이콘)를 클릭하여 인라인 편집**한다.
- 사용자는 더 이상 사용하지 않거나 잘못 등록된 링크를 화면에서 숨기기 위해 **해당 링크 아이템 우측의 삭제(휴지통 ❌) 버튼을 클릭하여 즉시 삭제**한다.

## 3. 사용자 플로우 (Mermaid Flowchart)

```mermaid
flowchart TD
    %% 방문자 플로우
    subgraph 방문자 (Visitor)
        V_Start[프로필 URL 접속] --> V_View[화면 및 링크 확인]
        V_View --> V_Click[특정 링크 클릭]
        V_Click --> V_Count[시스템: 클릭 수 +1 연산]
        V_Count --> V_Move[목적지 외부 URL로 이동]
    end

    %% 소유자 플로우
    subgraph 소유자 (Owner)
        O_Start[구글 로그인] --> O_Check{최초 가입자인가?}
        O_Check -- Yes --> O_Init[지메일 기반 URL 자동 할당]
        O_Init --> O_MyPage
        O_Check -- No --> O_MyPage[마이페이지 관리 모드 진입]
        
        O_MyPage --> O_Preview[우측 상단 '내 페이지 보기' 클릭]
        O_MyPage --> O_EditProfile[이름/소개글 연필 아이콘 클릭 및 인라인 수정]
        
        O_MyPage --> O_LinkArea[링크 관리 영역]
        O_LinkArea --> O_Add[+ 링크 추가 클릭 후 텍스트/URL 인라인 입력]
        O_LinkArea --> O_Edit[기존 링크 내용 클릭 후 인라인 수정]
        O_LinkArea --> O_Delete[기존 링크 삭제 버튼 클릭]
    end
```
