# MyLink - 제품 요구사항 정의서 (PRD)

## 1. 프로젝트 개요
- **프로젝트명:** 마이링크 (MyLink)
- **목적:** 크리에이터 및 개발자들이 자신의 다양한 온라인 활동과 포트폴리오를 하나의 링크로 모아서 공유할 수 있는 심플하고 직관적인 프로필 링크 서비스 제공
- **대상 사용자:** 본인의 작업물과 소셜 미디어를 깔끔하게 전시하고 싶은 크리에이터 및 개발자
- **디자인 컨셉:** 아방가르드 타이포그래피와 구조적인 미니멀리즘 기반의 화이트 테마 (현재 디자인 컨셉 완벽 유지)

## 2. 핵심 기능 목록 (필수 기능)
> 본 PRD는 사용자가 요청한 제약 조건(테마, 드래그앤드롭, 이미지 업로드, 활성화 토글, 모바일 미리보기 등 제외)을 엄격히 반영하여 작성되었습니다.

### 2.1. 인증 및 계정 생성
- **구글 소셜 로그인 전용:** Firebase Authentication을 사용하여 오직 구글 계정으로만 가입 및 로그인 가능.
- **초기 프로필 자동 설정:**
  - 회원가입 시 구글 지메일 주소의 아이디 부분(앞부분)을 추출하여 `displayName`(URL 슬러그)으로 자동 설정.
  - 예: `hello@gmail.com` -> `displayName: hello` -> URL 경로: `domain.com/hello` (URL 경로에 `@` 기호 사용하지 않음)

### 2.2. 프로필 관리
- **유저네임(username) 및 디스플레이 네임(displayName) 구조화:**
  - `displayName`: URL 경로에 사용되는 식별자 (영문/숫자 기반).
  - `username`: 프로필 페이지 화면 최상단에 실제 노출되는 사용자의 이름.
- **프로필 수정 기능:** 
  - 설정 화면 또는 프로필 영역에서 `username` 및 `displayName` 수정 가능.
  - *참고: 프로필 이미지 업로드 기능은 제공하지 않음.*

### 2.3. 링크 관리 (인라인 편집)
- **링크 추가/수정/삭제:**
  - 별도의 팝업이나 폼 화면 이동 없이, 화면 내에서 텍스트를 바로 클릭하고 수정하는 **인라인 편집(Inline Edit)** 방식으로 링크 타이틀과 URL 수정.
- **파비콘 아이콘 자동 연동:**
  - 링크 아이템 표시 시, 구글 파비콘 API(`https://s2.googleusercontent.com/s2/favicons?domain={URL}`)를 활용하여 사용자가 입력한 URL의 파비콘을 아이콘으로 자동 추출하여 표시.
- **기능 제한 사항 (명시적 제외 기능):**
  - 링크 표시 순서 변경(드래그 앤 드롭) 불가.
  - 링크 활성화/비활성화 상태 토글 기능 없음.

## 3. 데이터베이스 모델링 구조 (Firebase Firestore)
Firebase의 Sub-collection(서브 컬렉션) 패턴을 활용하여 데이터를 구조화합니다.

- **`users` (Root Collection)**
  - `uid` (Document ID)
  - `email`
  - `displayName` (URL Slug 용도)
  - `username` (화면 표시 이름)
  - `createdAt`
- **`links` (Sub Collection: `users/{uid}/links`)**
  - `id` (Document ID)
  - `title` (링크 텍스트)
  - `url` (목적지 URL)
  - `createdAt`

## 4. 향후 추가 예정 기능
- **방문자 통계:** 프로필 전체 방문자 통계가 아닌, **각 링크별 클릭 조회수**를 추적하고 보여주는 기능으로 추후 고도화 예정.
